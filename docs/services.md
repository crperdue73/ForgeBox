# ForgeBox — the container catalog

ForgeBox ships 30+ services, grouped by purpose. Core services always deploy;
everything else is behind a **compose profile** so you can run exactly what your
hardware can carry.

## Overriding ports

Every host port above is set by an `FB_PORT_*` variable with the value shown as
its default. None of them need to be set for a normal install. They exist so a
second ForgeBox instance can run on the same host:

```bash
# .env for a second instance
COMPOSE_PROJECT_NAME=forgebox-2
FB_PORT_PORTAINER=19000
FB_PORT_NPM=180
FB_PORT_NPM_TLS=1443
FB_PORT_NPM_ADMIN=181
FB_PORT_NEXTCLOUD=18030
# ...and so on for whichever profiles you enable
```

The full annotated list lives in `.env.example`. Two notes about how these are
used:

- **Same host port on two protocols is legal and expected.** Pi-hole uses one
  `FB_PORT_PIHOLE` for both TCP and UDP 53; Syncthing uses one
  `FB_PORT_SYNCTHING_SYNC` for both TCP and UDP 22000. That is not a collision.
- **`FB_PORT_OFFSET` does not exist.** There is no arithmetic in compose
  interpolation; set the individual values.

## Sizing guidance

- **core** — ~1.5 GB RAM, small disk. Fine on a 2c/4G box.
- **+devops** — Jenkins is the hungry one (1–2 GB). Gitea/Semaphore are light.
- **+media** — Jellyfin transcodes on CPU; \*arr + qBittorrent add ~1 GB. Disk grows fast.
- **+productivity** — Home Assistant is light; Paperless pulls in Postgres + Redis.
- **+files** — Nextcloud + Syncthing are storage-bound, not CPU-bound.

## How profiles work

Profiles are additive. A service with `profiles: [devops]` starts only when you pass
`--profile devops`. Core services have `profiles: []` and always start.

```bash
docker compose --profile devops --profile media up -d
```

The `vpn` profile (Gluetun) is kept out of `security` so the security profile runs clean
without a VPN gateway. **Note the wildcard `--profile "*"` does include `vpn`** — on a
host without `/dev/net/tun` that run brings up everything else and then errors on
Gluetun alone. Opt in explicitly with `--profile vpn` (device present), or list
every profile *except* `vpn` for a full bring-up on a tun-less host.
